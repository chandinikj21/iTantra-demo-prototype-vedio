iTantra is an offline-first, speech-driven communication system built for disaster zones, remote military outposts, and low-bandwidth radio links where the internet and cellular networks fail. It runs 100% on-device — no cloud, no internet — turning any Android phone into a resilient voice transceiver over ultra-low-bitrate channels.

Built for Smart India Hackathon 2026, Problem Statement SIH26173: "Indian Multilingual TTS & STT Aided Neural Transceiver Radio Access for Low Bitrate Links."

🔧 Core idea: instead of transmitting raw audio or plain text, iTantra converts speech into a compact semantic packet — as small as 5–15 bytes — protected with Reed-Solomon + LDPC error correction, and reconstructed as natural speech in the sender's own voice on the receiving end. Emergency messages carry a priority flag that overrides playback instantly, uninterrupted, at max volume.
